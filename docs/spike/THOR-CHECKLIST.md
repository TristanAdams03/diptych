# Thor checklist (KH1 spike)

You need GameNative 1.3.0 or newer.

## Read this first

The banner measures the mod's own thread. It does not measure the game's main loop.
STALLED means the mod, or the whole game process, stopped. For example, GameNative paused it.
STALLED is not proof that the game's frame loop is running or frozen.

## Steps

1. From the release, download `Diptych-KH1-mod-v0.0.1-kh1-spike.zip` and `Diptych-v0.0.1-kh1-spike.apk`.
2. Open GameNative. Open the page for KH 1.5+2.5.
3. Tap Mods, then Import.
4. Pick the zip.
5. Enable the mod. GameNative adds the `dinput8` DLL override by itself.
6. Install the APK. Open "Diptych (spike)".
7. If needed, move the app to the bottom screen.
8. Launch KH1 and load a save.
9. Write down the banner: ALIVE, STALLED or SOCKET DEAD.
10. Write down the HP and the world and room shown.
11. Check the controls still work.
12. Tap the bottom screen 5 times. Check the game keeps running.
13. Tap **Fetch mod log**. (The game folder is private on Android, so this is the only way to get the log.)
14. Tap **Copy report**.
15. Paste both to Claude.
16. Optional: try **Focus mode** and say what it does.

## Uninstall

1. In GameNative, open Mods.
2. Remove the mod.
3. Launch KH1 and check it still starts.
